# Как развернуть тестовый проект

1. [Установите Rust](https://rust-lang.org/) следуя [официальной инструкции](https://rust-lang.org/tools/install/)
2. Соберите тестовый проект:
    * Перейдите в директорию с проектом `<путь-до-репозитория>/rust`
    * Выполните в терминале команду `cargo build`
    * Запустите проект командой `cargo run -p practice01`, должно появиться пустое окно (возможно, чёрного или розового цвета)
